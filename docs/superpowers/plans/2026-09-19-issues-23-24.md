# Fix Issues 23 and 24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair malformed localization CSV handling in #23 and make Window Hole drag-and-drop plus second-layer state semantics deterministic in #24.

**Architecture:** Keep the existing native `SetWindowRgn` Window Hole implementation, but separate logical CSV record parsing from field parsing and make the second penetration target an explicitly locked runtime state. During Window Hole activation, the existing CapsLock mouse-button opacity handlers are disabled so real mouse input can reach the exposed lower window.

**Tech Stack:** AutoHotkey v2, native Win32 User32/GDI/DWM APIs, CSV text resources, GitHub Actions.

**Spec:** GitHub Issues #23 and #24 in `CYoJkoY/CapsLock-`.

## Global Constraints

- Do not modify or merge `main`; all changes are made on `fix/issues-23-24-window-hole-localization`.
- Preserve the public CapsLock + X shortcut and existing Window Hole settings.
- Use native Window Region behavior; do not replace the hole with an opacity or alpha overlay.
- Releasing CapsLock + X must restore every affected window to its prior state.
- CSV parsing must support quoted fields containing physical newlines and must reject malformed records instead of silently compiling partial data.
- Second penetration must select and lock one concrete secondary window when CapsLock + 1 is pressed.
- The existing CapsLock + LButton/RButton/MButton opacity shortcuts must remain unchanged when Window Hole is inactive.

## Review Focus

- Quoted CSV fields spanning physical newlines must remain one logical record; regression test covers this.
- Unterminated CSV quoted fields and wrong field counts must fail parsing; regression test covers both.
- CapsLock mouse-button opacity handlers must not intercept input during Window Hole; source regression test pins the guard.
- Layer 2 must remain locked to its selected target instead of continuously rediscovering deeper windows; source regression test pins the state model.
- Layer/session reset must clear the secondary target and localization cache must continue to load after rebuilding; source/resource regressions are checked in the test runner.
